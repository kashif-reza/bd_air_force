Bangladesh Air Force - Guardians of the Skies 🇧🇩✈️

A modern, responsive landing page for the Bangladesh Air Force (BAF) showcasing its history, organizational structure, strategic bases, fleet inventory, career options, and future modernization goals under Forces Goal 2030.

📌 Features

Hero Section: Full-screen background with call-to-action buttons.

Mission & Overview: Highlighted key defense and humanitarian roles.

Historical Genesis: Timeline layout detailing the origins of "Kilo Flight" during the 1971 Liberation War.

Command Structure: Interactive card layout for HQ commands and leadership.

Strategic Air Bases: Grid layout highlighting primary operational bases across Bangladesh.

Aircraft Inventory: Detailed categorization of combat aircraft, transport planes, trainers, helicopters, and UAVs.

Careers & Ranks: Information on joining the BAF Academy along with full officer and airmen rank hierarchies.

Forces Goal 2030: Modernization plans covering 4.5 Gen fighters, IADS radar systems, electronic warfare, and infrastructure updates.

🛠️ Technologies Used

HTML5: Semantic structural layout.

Tailwind CSS (CDN): Modern utility-first styling.

Font Awesome 6 (CDN): Icons for aviation, military, and navigational components.

Google Fonts:

Rajdhani (Headings)

Roboto (Body)

🚀 Getting Started

Clone or download this repository.

Open the index.html file in any modern web browser (Chrome, Firefox, Edge, Safari).

Ensure an active internet connection to load CDN dependencies (Tailwind CSS, Font Awesome, Google Fonts).
